# Darkhost 3D Showroom

Interactive 3D map of the Darkhost CRM enterprise (carpet cleaning): reception, workshop, docks, routes and a residential district with delivery vans, staff and pedestrians. Built with Three.js.

## Online

**Live demo:** https://voris-ai.github.io/darkhost-3d-showroom/

Permanent 24/7 cloud hosting via GitHub Pages. Works on any device without local server.

## Run

```bash
node server.js
# open http://localhost:5500
```
